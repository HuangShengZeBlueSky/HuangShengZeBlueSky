### 智能体评测

- [τ²-Bench 基准审计](https://github.com/HuangShengZeBlueSky/tau2-benchmark-audit)：从任务、用户模拟器、环境和评分器追踪失败原因，整理四个案例及上游反馈。
- [Qwen 轨迹审计](https://github.com/HuangShengZeBlueSky/tau2-qwen-case-audit)：整理 36 条 τ²-Bench 交互轨迹，支持逐案例检查模型行为与评测结果。
- [DeepSeek 轨迹审计](https://github.com/HuangShengZeBlueSky/tau2-deepseek-case-audit)：围绕 DeepSeek 用户模拟器与裁判，组织 τ²-Bench 轨迹的交互审计。
- [多智能体协作评测](https://github.com/HuangShengZeBlueSky/MPE_muiltiagent_benchmark)：连接语言模型与九种 MPE 环境，记录观测、动作及协作过程。
